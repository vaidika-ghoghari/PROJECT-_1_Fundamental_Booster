# 🧑‍💻 Interactive Personal Data Collector

This is my **first Python project**.

It is a simple interactive program that collects personal information from the user and displays the collected data along with its **data type** and **memory address**.

I created this project to practice the basics of Python and understand how user input, type conversion, variables, and built-in functions work.

---

## 📌 What This Project Does

The program asks the user for:

* 👤 Name
* 🎂 Age
* 📏 Height in meters
* 🔢 Favourite number

After taking the input, it displays:

* The entered information
* Data type of each value
* Memory address of each value
* Approximate birth year based on the entered age

While making this project, I practiced:

## ▶️ How to Run

Make sure Python is installed on your computer.

1. Clone this repository.
2. Open the project folder in VS Code or any Python editor.
3. Run the Python file.

```bash
python main.py
```
